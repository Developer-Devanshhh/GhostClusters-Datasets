# GhostClusters-Datasets (archived)

This repository is archived and no longer maintained. Code and data documentation for the study are
now maintained in **https://github.com/Developer-Devanshhh/ghostcluster**; see
[data/README.md](https://github.com/Developer-Devanshhh/ghostcluster/blob/main/data/README.md) there for
instructions on obtaining and placing the data.

> Devansh Verma and Kalyanaraman Pattabiraman.
> *Ghost Clusters: Detecting Patient-Reported Adverse Drug Event Expressions That Fall Outside Controlled
> Medical Terminologies.* Manuscript under review.

## Data sources

No data are hosted here or in the code repository. All data are available from their original providers,
under their own terms.

| Resource | Source | Access |
|---|---|---|
| SMM4H-2017 Task 3 | Sarker et al., *J. Am. Med. Inform. Assoc.* 25, 1274-1283 (2018) | Mendeley Data, https://doi.org/10.17632/rxwfb3tysd.2 |
| CADEC v2 | Karimi et al., *J. Biomed. Inform.* 55, 73-81 (2015) | CSIRO Data Access Portal, https://doi.org/10.4225/08/570FB102BDAD2 |
| PsyTAR | Zolnoori et al., *J. Biomed. Inform.* 90, 103091 (2019); *Data Brief* 24, 103838 (2019) | Data article, https://doi.org/10.1016/j.dib.2019.103838 (AskaPatient terms of use apply) |
| MedDRA 24.0 (English) | MedDRA Maintenance and Support Services Organization (MSSO) | Licence from MSSO, https://www.meddra.org/how-to-get/subscription |
